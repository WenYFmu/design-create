# Slidev Miracle Theme

Generate presentations with Slidev using the Miracle theme.

## Installation

```bash
npm install slidev-theme-miracle
```

## Available Layouts

| Layout | Description |
|--------|-------------|
| `center` | Center content |
| `cover` | Cover page |
| `default` | Standard layout |
| `end` | End page |
| `image-left` | Image left, content right |
| `image-right` | Image right, content left |
| `two-cols` | Two columns |

## Theme Features

- Clean and modern design
- Optimized for technical presentations
- Support for code highlighting
- Built-in animations
