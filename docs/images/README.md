## 📐 截图规范

### 通用要求

- **浏览器**：推荐使用 Chrome，隐藏书签栏
- **分辨率**：优先使用 1440 × 900 或 1920 × 1080
- **内容**：使用有意义的示例数据，避免空白或测试数据
- **语言**：界面语言保持中文
- **隐私**：确保截图中不包含真实的 API Key、密码等敏感信息

### 文件命名规范

```
screenshot-{功能描述}.png      # 静态截图
demo-{功能描述}.gif            # 动态演示
banner.{png|svg}               # Banner 图片
architecture.{png|svg}         # 架构图
```

### GIF 录制建议

- 帧率：15 FPS
- 尺寸：800 × 600 或 1024 × 768
- 时长：10-30 秒
- 文件大小：控制在 5MB 以内
- 循环：设置为无限循环

## 🔄 替换占位符

截图准备好后，在 `README.md` 中将 `https://via.placeholder.com/...` 替换为相对路径：

```markdown
<!-- 替换前 -->
![主界面](https://via.placeholder.com/580x360/EEEEEE/999999?text=主界面截图)

<!-- 替换后 -->
![主界面](docs/images/screenshot-home.png)
```
