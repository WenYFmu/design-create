# 为 GitHub 仓库添加 README 文档、截图演示和部署说明

## 项目概览

**design-create** 是一个基于 Spring Boot 3.5 + Java 21 的 AI 驱动设计/代码生成平台，使用 LangChain4j 集成大语言模型（通义千问），支持生成 HTML、多文件（HTML+CSS+JS）和 Vue 项目代码，并集成了 Slidev 幻灯片生成能力。

**GitHub 仓库**: `WenYFmu/design-create`

---
